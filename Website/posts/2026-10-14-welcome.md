## How it works

Add a file to `posts/` named `YYYY-MM-DD-some-title.md`, then push. That's all.

**Bold**, *italic*, [links](https://github.com/Gautam-Kumaran), lists, tables, and images (`![alt](images/chart.png)`, with the file in `posts/images/`) all work.

Inline math like $H = -\sum_i p_i \log p_i$ and display math:

$$
\beta = \frac{\mathrm{Cov}(r_s, r_m)}{\mathrm{Var}(r_m)}
$$

```python
def shannon_entropy(p):
    p = p[p > 0]
    return -(p * np.log(p)).sum()
```
